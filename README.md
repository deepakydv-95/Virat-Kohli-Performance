# 🏏 Virat Kohli Performance Analysis | Power BI

## 📌 Project Overview

This project presents an interactive **Power BI dashboard** analyzing the batting performance of **Virat Kohli** across **Test, ODI, and T20** cricket formats from **2008 to 2022**.

The dashboard provides insights into his scoring patterns, opponent-wise performance, ground-wise performance, and performance trends over time using interactive Power BI visualizations and DAX measures.

---

## 🎯 Objectives

* Analyze Virat Kohli's overall batting performance.
* Compare performance across **Test, ODI, and T20** formats.
* Identify the grounds where he scored the most runs.
* Analyze performance against different opponent teams.
* Track runs across months and years.
* Identify his highest-scoring performances.
* Create a **Performance Index** to compare his performance across formats.

## 📐 DAX & Analysis

DAX measures were created to calculate important performance metrics such as:

* Total Runs
* Maximum Runs
* Average Run Rate
* Match Count
* Runs by Format
* Runs by Opponent
* Runs by Ground
* Performance Index

The dashboard uses these measures to provide dynamic results based on the selected filters.
